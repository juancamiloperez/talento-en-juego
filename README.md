# Talento en Juego

Aplicación web para la asignatura de **Administración del Talento Humano** (programa de Administración Comercial).

Incluye dos actividades:

1. **Simulador de decisiones (3D):** el estudiante dirige el área de talento humano de una empresa ficticia, toma 8 decisiones (reclutamiento, selección, inducción, evaluación del desempeño, compensación, relaciones laborales, capacitación y desvinculación), enfrenta 2 eventos sorpresa y obtiene puntaje, nota de 1,0 a 5,0 y perfil.
2. **Taller de los 7 hábitos:** una actividad práctica por cada hábito de Stephen Covey (círculos de influencia, misión personal, matriz del tiempo, negociación ganar-ganar, escucha empática, sinergia y renovación).

## Cómo se usa

- El estudiante ingresa con sus nombres completos y número de cédula.
- Al terminar, copia o descarga su **comprobante** y lo envía al docente.
- En esta versión publicada en GitHub Pages los resultados **no se envían a ningún servidor**: el avance del taller se guarda solo en el navegador del estudiante.

## Publicación

El sitio es un único archivo `index.html`, publicado con GitHub Pages desde la rama `main`. Requiere conexión a internet para cargar la librería 3D (Three.js) y las fuentes.

## Aviso

Los contenidos legales mencionados en el simulador son referencias generales sobre la normativa laboral colombiana con fines educativos; no constituyen asesoría jurídica.
